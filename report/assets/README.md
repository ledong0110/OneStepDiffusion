`teacher_preview_sd15.json` is the primary preview. It contains eight authentic
512×512 SD 1.5 images at 64 DDIM steps / 128 NFE, using the eight fixed prompts
in `sd_models.PREVIEW_PROMPTS`, seed 12345, CFG 7.5. These are illustrative
general-scene prompts, not COCO evaluation captions. The report displays the
first four consecutively, without quality-based selection. Regenerate with
`python scripts/make_teacher_preview.py --gpu GPU_INDEX`.

The legacy `teacher_preview.json` contains authentic samples generated by
`scripts/make_teacher_preview.py` using the pinned `google/ddpm-cifar10-32`
checkpoint and evaluation seed 12345. Its rows use 64, 4, and 1 deterministic
DDIM evaluations. These files preview the qualitative layout before completed
experiment samples are imported. They contain no student outcomes or metric
measurements, and are not imported as research result JSONs.

The report builder replaces this reference preview when actual evaluation sample
images are available. New evaluation JSONs embed eight PNG images, so the sample
comparison works when team members send JSON files without external PNGs.
